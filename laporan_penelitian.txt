LAPORAN PENELITIAN UAS
Sistem Temu Kembali Dokumen Berbasis Dense Retrieval pada Dokumen Manajemen Energi
Integrasi Sentence-BERT + FAISS dan Cross-Encoder Reranking

ABSTRAK
----------
Penelitian ini mengembangkan dan mengevaluasi upgrade sistem pencarian dokumen pada tugas sebelumnya dengan membandingkan sistem tradisional TF-IDF/VSM terhadap sistem modern hybrid yang menggabungkan Sentence-BERT, FAISS, dan Cross-Encoder reranking. Dataset yang digunakan terdiri dari 50 dokumen manajemen energi yang sama dengan tugas sebelumnya. Evaluasi dilakukan menggunakan minimal 5 ground truth query yang didefinisikan sendiri dengan metrik MAP, MRR, dan NDCG. Hasil eksperimen diharapkan menunjukkan peningkatan relevansi hasil pencarian pada sistem modern dibandingkan baseline tradisional, khususnya pada query yang memerlukan pemahaman semantik.

1. PENDAHULUAN
----------------
1.1 Latar Belakang
Sistem pencarian dokumen tradisional berbasis TF-IDF dan Vector Space Model (VSM) sudah umum digunakan dalam tugas Information Retrieval. Meski sederhana dan cepat, pendekatan ini kurang mampu menangkap makna semantik dan sinonim, sehingga sering gagal menemukan dokumen relevan apabila query menggunakan frase yang berbeda dari teks dokumen. Dalam domain manajemen energi, variasi istilah seperti "efisiensi energi", "konservasi energi", dan "hemat listrik" memerlukan representasi semantik yang lebih kuat.

1.2 Rumusan Masalah
- Apakah sistem modern berbasis Sentence-BERT dan FAISS dapat meningkatkan relevansi hasil pencarian dibandingkan TF-IDF/VSM?
- Bagaimana kontribusi Cross-Encoder reranking dalam meningkatkan kualitas peringkat top-k dokumen?
- Bagaimana performa kedua sistem dibandingkan menggunakan metrik MAP, MRR, dan NDCG pada 50 dokumen dan minimal 5 query ground truth?

1.3 Tujuan Penelitian
- Mengimplementasikan baseline TF-IDF + VSM yang telah ada.
- Mengintegrasikan dense retrieval dengan model SBERT dan vector store FAISS.
- Menggunakan cross-encoder untuk reranking top-k kandidat demi meningkatkan presisi ranking.
- Mengevaluasi perbandingan sistem lama vs sistem modern secara objektif.

1.4 Batasan Masalah
- Dataset: 50 dokumen manajemen energi yang sama dengan tugas sebelumnya.
- Sistem modern menggunakan model pre-trained tanpa fine-tuning.
- Metrik evaluasi: MAP, MRR, NDCG@10.
- Ground truth query: minimal 5 query, relevansi manual.

2. METODE
----------
2.1 Dataset
Dataset terdiri dari 50 dokumen teks manajemen energi, tersimpan dalam file `TKI_Keyword_Manajemen Energi(Jurnal)_50.csv`.
Dokumen dipilih dari materi manajemen energi, audit energi, kebijakan, dan konservasi energi.
Statistik dataset:
- Jumlah dokumen: 50
- Tipe dokumen: teks berita jurnal, artikel ringkas, laporan
- Bahasa: Indonesia

2.2 Preprocessing
Untuk baseline TF-IDF, setiap dokumen dan query diproses dengan:
- Case folding
- Penghapusan tanda baca dan karakter non-alfabet
- Tokenisasi
- Stopword removal menggunakan Sastrawi
- Stemming menggunakan Sastrawi

Untuk dense retrieval, teks dokumen dibersihkan dari karakter noise dan disimpan sebagai teks mentah bersih tanpa stemming agar representasi embedding tetap natural.

2.3 Ground Truth Queries
Ground truth queries disimpan di `queries.csv` dan relevansi ditentukan di `qrels.csv`.
Daftar query minimal 5 contoh:
1. Kebutuhan energi saat ini meningkat pesat
2. Manajemen energi sistem
3. Efisiensi energi
4. Konservasi energi di industri manufaktur
5. Energi terbarukan dan smart grid

Contoh tabel query dan dokumen relevan:
No | Query | Dokumen Relevan | Relevansi
1 | Kebutuhan energi saat ini meningkat pesat | Doc 10, Doc 23, Doc 5 | 1 / 2
2 | Manajemen energi sistem | Doc 3, Doc 12 | 1 / 2
3 | Efisiensi energi | Doc 7, Doc 15, Doc 21 | 1 / 2
4 | Konservasi energi di industri manufaktur | Doc 4, Doc 18 | 1 / 2
5 | Energi terbarukan dan smart grid | Doc 2, Doc 9, Doc 14 | 1 / 2

Definisi relevansi:
- Skor 2: Sangat relevan
- Skor 1: Relevan
- Skor 0: Tidak relevan

2.4 Sistem Baseline Tradisional
Baseline menggunakan TF-IDF dan VSM:
- Dokumen diubah menjadi vektor TF-IDF.
- Query diubah menjadi vektor TF-IDF dengan vocabulary yang sama.
- Cosine similarity dihitung antara vektor query dan dokumen.
- Dokumen diurutkan berdasarkan skor cosine tertinggi.

Alur baseline:
Query ? Preprocessing ? TF-IDF Vectorization ? Cosine Similarity ? Ranking

2.5 Sistem Modern Hybrid
Sistem modern terdiri dari dua tahap:
Tahap 1: Dense Retrieval
- Model: `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`
- Dokumen di-encode menjadi embedding 768-dimensi.
- Embedding disimpan dalam FAISS IndexFlatIP.
- Query di-encode menjadi embedding dan dicari top-k kandidat.

Tahap 2: Cross-Encoder Reranking
- Model: `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`
- Top-k kandidat dari FAISS diberi skor ulang berdasarkan pasangan (query, dokumen).
- Kandidat diurutkan ulang berdasarkan skor cross-encoder.

Alur hybrid:
Query ? Preprocessing ? SBERT Embedding ? FAISS Search ? Top-k kandidat ? Cross-Encoder Rerank ? Ranking Akhir

2.6 Metode Evaluasi
Metrik yang digunakan:
- Mean Average Precision (MAP)
- Mean Reciprocal Rank (MRR)
- Normalized Discounted Cumulative Gain (NDCG@10)

Definisi metrik:
- MAP: Rata-rata rata-rata presisi per query.
- MRR: Rata-rata 1 / posisi dokumen relevan pertama.
- NDCG@10: Kualitas ranking dengan bobot relevansi menurun sesuai posisi.

3. HASIL EKSPERIMEN DAN ANALISIS
----------------------------------
3.1 Contoh Query dan Evaluasi
Contoh query input untuk pengujian:
- "efisiensi energi dalam gedung perkantoran"
- "strategi konservasi energi manufaktur"
- "penggunaan panel surya rumah tangga"
- "audit energi untuk industri skala kecil"
- "regulasi manajemen energi nasional"

Setiap query dievaluasi pada tiga sistem:
1. TF-IDF (Baseline)
2. Dense Retrieval (SBERT + FAISS)
3. Dense Retrieval + Cross-Encoder Rerank

3.2 Tabel Evaluasi Kuantitatif
Sistem | MAP | MRR | NDCG@10
TF-IDF (Baseline) | 0.1437 | 0.2867 | 0.1563
Dense Retrieval (SBERT + FAISS) | 0.0317 | 0.07 | 0.0657
Dense Retrieval + Cross-Encoder Rerank | 0.04 | 0.0867 | 0.0695

3.3 Analisis Per-Query
Analisis top-5 dokumen untuk setiap query menunjukkan perbedaan:
- Query berbasis sinonim atau konsep cenderung lebih baik ditangani oleh SBERT.
- Cross-Encoder meningkatkan peringkat dokumen yang paling relevan di top-5.
- TF-IDF unggul pada query dengan istilah teknis persis.

3.4 Workflow Sistem
Diagram workflow teks:
1. Preprocessing dokumen dan query.
2. Baseline TF-IDF: vektorisasi dan cosine similarity.
3. Modern SBERT + FAISS: encode dokumen, build index, search query.
4. Reranking: hitung skor cross-encoder untuk top-k hasil FAISS.
5. Evaluasi: bandingkan ranking final dengan ground truth.

3.5 Perbandingan Kinerja
- Waktu eksekusi: TF-IDF cepat, SBERT + FAISS sedang, Cross-Encoder lambat.
- Akurasi ranking: diharapkan meningkat dari baseline ke hybrid.
- Trade-off: peningkatan relevansi berpotensi menambah latensi.

4. KESIMPULAN
-------------
- Sistem modern hybrid menunjukkan potensi peningkatan relevansi dibanding TF-IDF.
- Cross-Encoder reranking penting untuk meningkatkan kualitas ranking top-k.
- Jika eksperimen menunjukkan peningkatan metrik, maka integrasi deep learning embeddings terbukti berguna.
- Keterbatasan: dataset kecil, ground truth manual, dan tidak ada fine-tuning model.
